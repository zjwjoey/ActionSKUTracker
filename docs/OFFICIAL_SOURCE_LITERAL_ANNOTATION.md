# 官网异常原词的可审计中文表示

用户在 2026-10-12 审查 50 项来源复核候选后明确回复“按照官网上的信息来”。本规则尚在隔离开发分支，不表示已部署 daily 主线。

原则：西语事实不改；成分比例、数量、单位与速率不根据常识修正。无法解释的物态原词以及 `inoloras` 明确标注为来源异常，不能译成猜测的凝胶、液体、无痛或无香。已知的 Loción 可按本字段译为乳液，异常 Válido 仍保留。

`OFFICIAL_SOURCE_LITERAL_ANNOTATION_V1` 复用现有 SemanticFact 与 Registry provenance，不新增数据库 schema。认可一段原词标注需同时满足：

1. 有有限 Owner 授权文件，实际授权文字、引用、scope和文件SHA绑定。
2. SKU、字段、本字段来源hash、原词和完整标注均逐项匹配。
3. 物态源确有 Válido 类损坏值；目标标注必须位于对应属性的原位置，字段对数不变。
4. 不得共存猜测的物态字段；数字、单位、型号、认证、否定、普通西语与 canonical QA 继续正常运行。
5. 默认无授权仍为 SOURCE_DETAILS_TYPED_VALUE_INVALID 阻塞；文件缺失、被改、来源变化、串SKU、错字段或错误标注均拒绝。
6. 正式写入仍走独立语义审核、QA、代理审批、不可变补丁和 Apply。批准后的来源/中文hash与字段provenance一致才可在导出复用。

这里的 QA PASS 表示“忠实、明确地表示官网原文”，不表示“官网数据本身正确”。审计单独保留 `declared_source_anomalies`；不以低字段错误率放宽 P0、来源绑定、审批或完整性门禁。

Owner 授权文件是运行证据的一部分，必须随备份及审计保留；丢失时仍会阻断该标注的发布。历史重放与另一个运行环境需要完整证据文件，不能仅迁移 Excel 或删除 runtime 证据目录。
