## 全量复核后追加修复

共享 `localization/fidelity.py` 负责字段内品牌/系列身份、品名 NO_BRAND、颜色/材质属性完整性及来源计数量词。描述与详情的品牌来自其自身西语字段；品名不能授权其他字段添加品牌或数字。详情按属性位置保持重复键及顺序，管道符只在明确的新属性键前拆分。

QA 增加相同来源约束；橡皮、MDF、尺码范围和文字数量只在明确语境下等价匹配。数字变动、错误品牌、颜色遗漏、不同尺码端点仍阻断。`tests/test_current_fidelity_contract.py` 覆盖正确等价和错误拒绝。

既有正确 PRIMARY 中文不生成重复内容补丁；导出层错误由程序修复。新增候选仍须独立字段复核、QA、有限代理审批、不可变 patch、Apply，并对照恢复校验通过的备份验证事实、历史及非在售中文不变。隔离分支改动尚未部署。

### 本批最终回归新增契约

- 普通显示词白名单不能当作品牌证据；发布审计的品牌事实只来自确认的品牌字典与字段复核证据。
- `Material` 的基材、把手、盖子、镜片及框架角色分别核对；Sustancia=纸可合法译作材质或形态，不把不同角色混算。
- 同一来源下，更新且来源 hash / 内容 / CURRENT / 审批身份均匹配的 PRIMARY 译文优先于较旧的导出 override，并记录 KEEP 事件。无效来源或审批不享有该优先级。
- 品名实际执行来源绑定的中文品牌别名清理；删除品牌后的“的”也移除。Coca-Cola 明示 Cola 主体保留为“可乐”，Zero 变体保留，不把产品名清成孤立修饰词。
- 无冒号的损坏 `Incluye oído Sí/No` 按有限官方标签恢复解析边界，原始字段及 hash 不改。附带布尔标签和杯子类型同样保留 source_text。新增 4 个同类真实问题复用有限代理审批和原词异常标注，不猜“带把手”。
- 西语展示抑制完全相同的重复属性，而中文忠实保留 PRIMARY 原始重复。复核须回查 PRIMARY 来源后标记展示差异，不能误报成翻译新增事实。不同值的重复键不得折叠。
