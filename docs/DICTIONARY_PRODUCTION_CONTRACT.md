# Dictionary Production Contract

Resolver priority is locked manual, human-approved product dictionary, human-approved scoped rule, approved category/term rule, validated product dictionary, valid model cache, and AI candidate. Missing or stale values remain `PENDING`/`REVIEW_REQUIRED`; `display_fallback=ES` is presentation-only and cannot enter formal Chinese or release readiness. Apply requires a fresh source hash, current database head, approved provenance, PRIMARY role and explicit production enablement. It never writes Master.xlsx or Spanish facts.
