# P8 Control Center Runbook

Start with `python -m action_tracker ops status`, `ops runs`, `ops run <RUN_ID>` and `ops health`. For a local read-only dashboard use `python -m action_tracker ops serve --host 127.0.0.1 --port 8787`. Safe action responses require explicit confirmation and return the existing CLI command; V1 never directly updates products, lifecycle, localizations or events. Review high-risk actions and use the existing audited CLI contracts.
