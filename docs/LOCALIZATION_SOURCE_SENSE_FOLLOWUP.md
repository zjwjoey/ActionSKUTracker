# 来源字段限定的 QA 释义修复

这些规则只识别已有中文候选是否表达了本字段的西语事实，不生成译文，不批准候选，不修改默认开关、来源、数据库结构或 daily-run。

- `Tipo de guantes: Manoplas` 接受连指手套/并指手套；`Manoplas de baño` 仍只按沐浴手套处理。其他字段的冬季品名不能提供本字段缺失的限定语。
- `aroma a madera de roble` 接受橡木香气/香调，不强迫加入木材组成断言。字段另有实际木材出现时仍保留木材检查；其他树种或仅泛称香气不通过该控制。
- 完整 `paño de cocina` 接受厨房用布等对应译法，并保留原有 canonical 检查控制；其他字段的厨房语境不能传播过来。
- 完整 `calcetines calados` 接受“镂空袜”复合词，不强制额外添加“子”。未限定的普通袜子来源不能借用此释义。

OB 品牌通过已有的字段级 `SemanticFact(BRAND)` 证据接口识别，证据来自 SKU 官方包装及品牌资料；没有新增全局缩写白名单。源冲突、数字、单位、型号、否定、来源 Hash、审批和 Apply 门禁保持原契约。

`tests/test_followup_localization_senses.py` 为 CI_SAFE 离线回归，覆盖正确译文、错误释义、跨字段上下文及独立词项，不能当作人工 Gold 或生产验收。
