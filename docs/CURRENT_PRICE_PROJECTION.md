# CURRENT 西中价格投影修复（本地已实现）

SQLite PRIMARY 的 `price_history` 与产品当前事实生成两张 CURRENT 表的同一份价格投影，不再保留 Excel 历史单元格作为事实来源。无需数据库结构迁移。

- 历史最低/最高价包含有效历史旧价、新价及当前价；无历史商品以当前有效价格初始化。
- 上次售价、变价方向、变化金额/幅度及日期表示最近一次真实变价；初始价格不伪装成涨跌。
- 本期价格变化按最新 committed head 的业务日期判断，无当期价格事件为 UNCHANGED。初始价格事件为 NEW。
- 百分比以 Excel 小数比率表达。折扣取当前有效促销徽章百分比，或有效原价与当前价计算；没有当前折扣证据则清空。
- 两表金额显示为欧元两位小数，变化幅度与折扣显示为百分比，避免中文表旧行丢失格式后将 -0.21 直接显示为小数。
- Excel Writer 按 SKU、Canonical_ID 列头定位身份，两张表使用同一 authoritative SKU 顺序，并保留行内单元格格式。

验证：`tests/test_current_price_projection.py`，仅内存工作簿及纯函数，CI_SAFE，无官网访问、模型调用或生产数据写入。本轮不改变一级类目和采集判断，不改变远端部署状态。
