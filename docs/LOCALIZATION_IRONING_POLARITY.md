# 详情熨烫禁令的属性级校验

2577090 的真实来源片段 `Instrucciones de planchado: Sin planchado` 要求禁止熨烫。
原规则仅拦截“无需/免熨”等弱化表达，允许错误的“可熨烫”通过。
该问题在当前复核的反例测试中发现，未将错误反例写入生产。

修复沿用 `CARE_INSTRUCTION_CHANGED`，只诊断详情中已明确禁止熨烫的属性：

- 同字段的熨烫条目按出现顺序配对，其他洗护属性不能提供否定依据。
- 拦截许可、遗漏、弱化及同条目中相互矛盾的许可表达。
- 保留明确禁止、合法布尔键极性，以及重复条目各自的含义。
- 正常温度熨烫、其他来源字段的文字不会触发此禁止校验。
