# Apply 预览 QA 修复范围（仅本地）

本轮只修复 Guard 的词义与匹配范围，不生成翻译、不晋升正式术语、不开启自动审批。

- `calcetines` 的保暖、女童、男童、居家复合名称只在本字段有对应限定语时认可。
- `detergente` 在完整 `Tipo de detergente de limpieza de WC:` 属性中按洁厕剂判断，不再强求“洗洁精”。
- `paño hidrofílico` 认可吸水布；普通清洁布不继承该词义。
- `goma` 仅在小熊软糖或本字段明确口服营养补充剂上下文中认可软糖；普通橡胶材料仍须保留橡胶含义。
- `Iluminación de la pantalla:` 认可屏幕照明／背光，不能用一个独立照明灯替代。
- 完整 `La Maison Rêve` 仅在本字段来源中出现时作为描述／详情品牌处理，其组成词及相邻西语不豁免。
- `FAB Factory` 的 FAB 仅在品名完整品牌跨度中可以按 NO_BRAND 省略；独立 FAB、重复出现在品牌外的 FAB 及正文仍受技术 token 保护。
